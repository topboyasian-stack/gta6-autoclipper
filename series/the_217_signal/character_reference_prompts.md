# THE 2:17 SIGNAL — Character reference generation

Create each character reference as a separate image in Google Flow or an image tool. Do not generate all three in one image. Save the approved result at the exact path shown in the series bible, inside the persistent Drive series workspace.

## Shared character-sheet requirements

- Premium cinematic 3D animation, grounded human proportions and restrained stylisation.
- One character only, full body, neutral standing pose.
- Neutral light-grey studio background, soft even light, no dramatic shadows obscuring facial features.
- Include front, three-quarter and side views in a clean turnaround sheet, plus one clear close-up portrait.
- Preserve natural anatomy, hands, facial structure, skin tone, hair texture and clothing details.
- No text, labels, watermarks, logos, jewellery or accessories not specified in the character lock.
- This is a production reference, not a poster or a scene.
- Use the same approved reference image for every later scene in which that character appears.
